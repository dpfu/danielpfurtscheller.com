Research tools

I built these tools for my own research with help from LLMs. They’re at different stages of development, and contributions are welcome. To adapt one, point your AI coding agent at the GitHub repository for SortBoard, Folder Sort or VideoBoard.

  • alpha/experimental

    SortBoard

    Run and replay visual sorting sessions with research participants.

    Try SortBoard ↗

  • beta/pre-release

    Folder Sort

    Explore an image collection on a board and export your sorting as a folder structure.

    Try Folder Sort ↗

  • alpha/experimental

    VideoBoard

    Arrange, annotate and code video clips on a spatial board.

    Try VideoBoard ↗
